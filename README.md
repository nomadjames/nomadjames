### 🎹 iOS Synthesizer

A touch- and sensor-controlled sound engine that interfaces with **Ableton Live** and **modular synthesizers** via MIDI.

- **XY Pad** — touch surface maps X-axis to pitch (in a musical scale), Y-axis to filter cutoff
- **Sensor Modulation** — accelerometer and gyroscope feed real-time MIDI CC values to Ableton
- **Virtual MIDI Port** — appears in Ableton's MIDI prefs over USB, no extra hardware needed

→ [View the iOS Synthesizer project](./ios-synthesizer/)
